# Team tools handbook
**Status:** example
**Owner:** platform team

This handbook is about the three tools you'll use every day: the sync agent, the command-line tool (CLI), and the desktop app. It comes in two voices, one for new hires and one for engineers, and both carry the same facts.

## Support tiers

When you open a request with the platform team, it gets exactly one of three support tiers:

- **Tier 1**: you'll hear back within one business day. This covers outages and anything that blocks a release.
- **Tier 2**: you'll hear back within three business days. This covers degraded behavior with a workaround.
- **Tier 3**: you'll hear back within ten business days. This covers questions, requests for new features, and documentation gaps.

The person who triages the request sets the tier, not the person who opens it. A request can move between tiers once triage has looked at it.

## How to read this handbook

**Recommended.** Start with the setup guide, then read the data-handling policy. The policy is short, and it's the one document everyone is expected to know.

The glossary in the reference section is a table, and it's identical in every voice. It's the one place where the wording never changes.
